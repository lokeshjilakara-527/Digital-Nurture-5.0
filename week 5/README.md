# Week 5 — React Mandatory Hands-on (ReactJS-HOL)

The 10 mandatory ReactJS-HOL exercises from the DN 5.0 sheet, each built to the actual
problem statement. One file per exercise in `src/handson/`.

| HOL | App name | What it does | File |
|-----|----------|--------------|------|
| 1 | myfirstreact | Welcome heading | `HOL01_myfirstreact.jsx` |
| 2 | StudentApp | Home / About / Contact components | `HOL02_StudentApp.jsx` |
| 3 | scorecalculatorapp | CalculateScore function component (avg) | `HOL03_scorecalculatorapp.jsx` |
| 4 | blogapp | Class component + componentDidMount/DidCatch | `HOL04_blogapp.jsx` |
| 5 | styling | CSS Module + inline styles (cohorts) | `HOL05_styling.jsx` (+ `.module.css`) |
| 9 | cricketapp | ES6 map/filter/destructuring/merge, flag if-else | `HOL09_cricketapp.jsx` |
| 10 | officespacerentalapp | JSX elements, attributes, image | `HOL10_officespacerentalapp.jsx` |
| 11 | eventexamplesapp | Events, counter, CurrencyConvertor | `HOL11_eventexamplesapp.jsx` |
| 12 | ticketbookingapp | Conditional rendering, login/logout | `HOL12_ticketbookingapp.jsx` |
| 13 | bloggerapp | 3 components, many conditional-rendering ways | `HOL13_bloggerapp.jsx` |

## Run
```bash
npm install
npm run dev      # http://localhost:5173 — use the tabs to view each HOL
```

Built to the real ReactJS-HOL problem statements (from the Cognizant reference repo).
Combined into one project so all 10 compile from a single `npm install`; each HOL is a
self-contained file you can lift into its own `create-react-app`/Vite project if required.
